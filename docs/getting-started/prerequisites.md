# Prerequisites

You need **no programming experience**. This course starts from zero.

## What you need

- A computer that can run Docker (Windows, macOS, or Linux).
- A modern web browser (Chrome, Edge, or Firefox).
- About 1 GB free disk for Docker Desktop + the tutorial image (~tens of MB).

## What you do NOT need

- No Python, MkDocs, Node.js, or npm on your computer.
- No accounts, no servers, no databases.
- No prior HTML, CSS, JavaScript, terminal, or editor experience.

## Terms you will learn (don't memorize now)

- **Browser** — the app that displays websites.
- **HTML** — structure and content of a page.
- **CSS** — appearance and layout.
- **JavaScript** — behavior and interaction.
- **File / extension** — why `index.html` works but `index.html.txt` does not.
- **Container** — a sealed box that runs the tutorial website for you.
