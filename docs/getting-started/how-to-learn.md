# How to Learn

Short missions, not a semester-long assignment.

## The loop for every lesson

1. **Read the goal** in plain English.
2. **Predict** what the code will do before running it.
3. **Run** the example (click Run Example or open the file).
4. **Change one thing** and observe. Break it safely — errors are normal.
5. **Verify** against the "What success looks like" checklist.

## Three levels

- **Level 1 — Follow Along:** reproduce the working example, understand each part.
- **Level 2 — Modify & Experiment:** change values/styles/conditions, predict first.
- **Level 3 — Build It Yourself:** requirements + hints + acceptance criteria, solution separate.

## Debugging routine (use every time)

1. Reproduce the problem.
2. Read the error message (browser console: `F12` → Console).
3. Check the file and line named.
4. Reduce to the smallest failing case.
5. Change one thing at a time.
6. Verify the fix.
