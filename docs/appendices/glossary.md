# Glossary

- **Attribute** — extra info inside an HTML opening tag (e.g. `href="..."`).
- **Box model** — content + padding + border + margin around every element.
- **Class / ID** — CSS hooks to style groups (`.name`) or one element (`#name`).
- **Container (Docker)** — sealed runnable box holding the tutorial website.
- **DOM** — the browser's object view of the page that JavaScript can change.
- **Element / Tag** — `<p>hello</p>`: opening tag, content, closing tag.
- **Event listener** — code that runs when something happens (click, typing, submit).
- **Flexbox / Grid** — CSS layout systems for 1D rows/columns and 2D grids.
- **Image / tag** — `focuslog/hello-web:1.0`: repository plus version label.
- **Media query** — CSS rule that adapts layout to screen size.
- **Semantic HTML** — tags that describe meaning (`header`, `nav`, `main`, `footer`).
- **`textContent` vs `innerHTML`** — safe text update vs HTML injection (prefer `textContent` for user input).
